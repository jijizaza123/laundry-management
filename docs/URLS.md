# 页面入口清单

> 地址前缀按你自己的环境替换：
> 本地调试 `http://127.0.0.1:8000`，线上 `http://<你的域名或服务器IP>:8000`

## 客户端（客户自己用）

| 页面 | 路径 |
|---|---|
| 客户登录 | `/me/login` |
| 首页 / 线上点单 | `/me` |
| 我的订单 | `/me/orders` |
| 消息中心 | `/me/messages` |
| 预约取衣 | `/me/book` |
| 客户助手（Agent） | `/me/chat` |

演示客户账号在 `scripts/seed_demo.py` 执行时打印（默认 `13800138000 / demo1234`）。

## 管理端（员工 / 店长）

| 页面 | 路径 |
|---|---|
| 员工登录 | `/login` |
| 收衣下单 | `/receive` |
| 订单管理 | `/orders` |
| 取衣结算 | `/pickup` |
| 会员管理 | `/members` |
| 库存耗材 | `/inventory` |
| 财务 | `/finance` |
| 复核调价 | `/review` |
| 预约管理 | `/appointments` |
| 指标看板 | `/metrics` |
| 员工助手（Agent） | `/chat` |

管理员密码由 `seed_demo.py` 随机生成，只打印一次，同时写到部署机的
`ADMIN_CREDENTIALS.txt`（不要把密码提交进仓库）。

## 系统

| 用途 | 路径 |
|---|---|
| 公开首页（分流两个入口） | `/` |
| 健康检查 | `/api/health` |
| 接口文档（Swagger） | `/docs` |

## 一次完整演示的走法

1. `/me/login` 用演示客户登录，进 `/me` 下一单
2. 换 `/login` 用管理员登录，进 `/review` 复核并调价
3. 回客户端 `/me/orders` 确认金额
4. 管理端 `/orders` 或 `/pickup` 把状态改成「可取衣」
5. 客户端 `/me/messages` 收到通知
6. 管理端 `/metrics` 看助手调用次数与耗时

## 端口与进程约束

- 容器固定单进程（动作卡在进程内存），不要开多 worker
- 宿主机若已有别的站点占用 80，直接暴露 8000 或另配反向代理
- 容器时区必须是 `Asia/Shanghai`，否则订单号与预计取衣时间会差 8 小时
